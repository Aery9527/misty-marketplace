# LORE

- This repository is an AI Agent Skills marketplace: it maintains reusable skills and publishes them as Plugin Bundles to Claude Code, GitHub Copilot CLI, and Codex.
- Discover skills by reading the YAML frontmatter (`name`, `description`) of each `skills/*/SKILL.md`; `SKILL.md` is the English entry, and a `*_ch.md` beside it is its Traditional Chinese counterpart.

## Directory Index

- [skills](skills) — skill source of truth; everything inside a skill directory ships with that skill
- [.claude-plugin/marketplace.json](.claude-plugin/marketplace.json) — catalog of bundles every host can install; its `metadata.version` is the repo-wide version
- [.agents/plugins/codex-only-bundles.json](.agents/plugins/codex-only-bundles.json) — catalog of bundles only Codex can install
- [.agents/plugins/marketplace.json](.agents/plugins/marketplace.json) and [codex-plugins](codex-plugins) — Codex package generated by the sync script; English primary files only
- [scripts](scripts) — sync, verification, and local link scripts
- [docs](docs) — maintainer-only documents, one `docs/<skill-name>/` directory per skill
- [release-note](release-note) — one release note per version
- [.claude/skills](.claude/skills) — repo-local `commit` and `release` skills for maintaining this repository

## Bundle Catalogs

- Declare each bundle in exactly one catalog, chosen by which hosts can install it:
    - [.claude-plugin/marketplace.json](.claude-plugin/marketplace.json) for a bundle every host can use; Claude Code and Copilot CLI read it, and Codex packages from the same entry.
    - [.agents/plugins/codex-only-bundles.json](.agents/plugins/codex-only-bundles.json) for a bundle only Codex can use, e.g. one whose skills drive another agent CLI.
    - The sync script rejects a bundle declared in both catalogs.
- When a skill is added, removed, renamed, or moved to another bundle, update the owning catalog first.

## Codex Package Sync

- After changing anything under [skills](skills) or either catalog, run [sync-codex-plugins.ps1](scripts/sync-codex-plugins.ps1) or [sync-codex-plugins.sh](scripts/sync-codex-plugins.sh).
- MUST NOT edit [.agents/plugins/marketplace.json](.agents/plugins/marketplace.json) or the skill copies under [codex-plugins](codex-plugins) manually; change the source and rerun the sync script.
- To add a Codex package, create `codex-plugins/<plugin>/.codex-plugin/plugin.json` first, then run the sync script; the script writes its `version`.
- Plugin-root content a Codex package needs beyond skills, such as `commands/`, `agents/`, `scripts/`, and `hooks.json`, lives in a `codex-plugin/` overlay directory inside the owning skill:
    - The sync script lifts the overlay's contents to the plugin root and excludes the overlay from the packaged skill.
    - An overlay owns only the entries it declares, and MUST NOT contain `.codex-plugin` or `skills`.
    - The sync script adds or removes the `"hooks": "./hooks.json"` declaration in `plugin.json` to match the overlay; MUST NOT edit it manually.

## Notes

- Keep AI-agent documents bilingual and equivalent: the file without a suffix is English, and the same basename plus `_ch` is Traditional Chinese, e.g. `SKILL.md`=`SKILL_ch.md`, `LORE.md`=`LORE_ch.md`.
    - This applies to `SKILL.md`, Markdown under `references/`, and root instruction documents.
    - Update both languages in the same change.
    - Traditional Chinese files link to `_ch` targets when such targets exist.
- Treat [README.md](README.md) as a human-reader document in Traditional Chinese only; keep it project-level and MUST NOT list the skills it contains, because the list drifts from the frontmatter.
- A document written only for a skill's maintainers MUST live under `docs/<skill-name>/`, not inside the skill directory.
- Inside `SKILL.md` or `references/`, MUST NOT use a relative Markdown link to another skill, because installed skills are not guaranteed to sit side by side; name it in inline code instead, e.g. `write-md`.

## Reading Guide

- [scripts/README.md](scripts/README.md) when running or changing the sync, verification, or link scripts.
- [docs/claude/UPSTREAM-PARITY.md](docs/claude/UPSTREAM-PARITY.md) before changing anything under `skills/claude/codex-plugin/`; update it in the same change.
