# log 範例

- 沒有結構化欄位慣例時，固定欄位位置讓 AI 對照程式碼解讀資料，減少重複說明占用的 log 空間與 token；可採 `Enter {AGE} {NAME} "{MSG}"`。
- 請求次數統計情境：上述 `Enter {AGE} {NAME} "{MSG}"` 表示每筆請求進入處理入口時的一次事件。
    - 若這些事件只用來統計請求次數，且允許遺失尚未輸出的計數，可在同一入口每收到一筆請求就將計數加一。例如每 5s 寫入一次 `Request ALL 123`，取代逐筆 `Enter` 紀錄。
    - `ALL` 表示該入口不依 `AGE`、`NAME` 或 `MSG` 分組的全部請求；`123` 表示該 5s 區間共收到 123 筆請求，各區間分開計數。
    - 若逐筆 `Enter` 紀錄另有診斷或稽核用途，仍保留這些紀錄，並可由此統計。
